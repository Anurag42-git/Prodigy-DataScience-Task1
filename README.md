# Task 1 - Data Visualization

## Objective
To create a bar chart or histogram to visualize data distribution.

## Dataset
World Bank Population Dataset

## Approach
- Loaded dataset using Pandas
- Cleaned dataset by removing aggregated regions
- Selected population data (2020)
- Created a professional bar chart of top 10 countries

## Output
Bar chart showing top 10 most populous countries

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
